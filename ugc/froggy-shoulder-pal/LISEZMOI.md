# 🐸🍓 Froggy Shoulder Pal : UGC Roblox (Shoulder)

Une petite grenouille toute ronde, assise sur l'**épaule droite**, avec un mini chapeau fraise. Elle existe en 5 coloris : Vert, Rose (fichier `Fraise`), Bleu, Citron et Choco.

![Les 5 coloris](previews/coloris.png)

Les étapes sont les mêmes que pour le Neko Bucket Hat (voir le [README principal](../../README.md)). Seuls ces points changent :

| Étape | Ce qu'il faut choisir |
|---|---|
| Import 3D | `fbx/FroggyShoulderPal_<Couleur>.fbx`. Taille affichée : environ **0,72 × 0,54 × 0,56** studs, **3 914 triangles** |
| Accessory Fitting Tool › Asset Type | **Accessory › Shoulder**, côté **droit** (`RightCollarAttachment`), body type **Classic** |
| Save to Roblox › Asset type | **Shoulder** |

**Placement attendu** : la grenouille est assise sur le dessus du bras droit, à environ 0,45 stud du cou, les pattes posées sur l'épaule, et elle regarde vers l'avant (légèrement tournée vers l'extérieur). Elle ne touche pas la tête.

**Si elle apparaît à moitié enfoncée dans l'épaule** (l'outil l'a centrée sur le point d'attache) : avec **Move**, monte-la d'environ **0,26 stud** et décale-la d'environ **0,44 stud vers l'extérieur** (vers la main), jusqu'à ce que ses pattes reposent sur le dessus du bras. Puis *Generate*.
